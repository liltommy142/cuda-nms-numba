Scope and claim boundaries
--------------------------
This submission evaluates deterministic synthetic NMS only: class-aware greedy
hard NMS with a NumPy CPU baseline, CUDA/Numba V1 dense IoU, and CUDA/Numba V2
packed suppression masks. It excludes detector inference, image preprocessing,
and model loading. The optional YOLO detector checkpoint is not included, so
this submission makes no detector-inference result claim. V3 Matrix NMS remains
a separate experiment and is not presented as hard-NMS parity.

Target status
-------------
The canonical catalog target is <5 ms/batch. The saved V2 batch-32 median is
947.180 ms total for 32 images (29.599 ms/image, contextual only), so the
canonical <5 ms/batch target is MISSED on the recorded RTX 4060 Ti environment.

Integrity procedure
-------------------
SHA256SUMS.txt lists lowercase SHA-256 digests using paths relative to this
directory, in lexical order. The checksum file intentionally does not hash
itself. Re-run `python -m pytest tests/test_submission_artifacts.py -q` from
the repository root after extracting the bundle to verify the manifest,
checksums, and executable report.
