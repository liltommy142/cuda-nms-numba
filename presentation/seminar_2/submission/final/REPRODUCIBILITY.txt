SEMINAR 2 REPRODUCIBILITY

Repository:
https://github.com/liltommy142/cuda-nms-numba

CUDA correctness:
python -m pytest tests -v

Repeated single-image benchmark:
python benchmarks/run_all.py --versions cpu v1 v2 v3 --repeats 7 \
  --json presentation/seminar_2/evidence/benchmark_t4_single.json

V2 batch-32 benchmark:
python benchmarks/run_v2_batch.py --batch-size 32 --n 10000 \
  --warmup 2 --repeats 7 \
  --json presentation/seminar_2/evidence/batch32_t4.json

Interpretation:
- V1 and V2 are validated against greedy CPU/torchvision NMS behavior.
- V3 is validated against matrix_nms_reference(), not torchvision hard NMS.
- The automated B=32 correctness test uses N=50.
- The B=32 latency benchmark uses N=10,000 and measures the end-to-end V2 call.
