# Presentation hub

This folder is organized by seminar so that proposal artifacts never mix with
final results or rehearsal material.

| Seminar | Purpose | Start here |
|---|---|---|
| [Seminar 1](seminar_1/README.md) | Submitted proposal and its original scope | Proposal deck and scope summary |
| [Seminar 2](seminar_2/README.md) | Implementation evidence, final deck, rehearsal and submission checklist | Seminar 2 readiness status |

Use only benchmark artifacts recorded in `seminar_2/evidence/` for final
performance claims. Historical proposal numbers are context, not final results.
